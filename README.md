# Survival Mode - Lite

In between vanilla and survival mode - fully customizable!

Starsector 0.98.5a added Survival mode, picked when you start a new game. This mod keeps everything
Survival mode does and halves every penalty: each number sits halfway between vanilla and survival.

Only campaigns started in Survival mode change. Normal campaigns are not touched.

## Everything Survival mode changes

Vanilla is the base game without Survival mode. Lite is the default of this mod. With LunaLib every value in these tables can be changed in the mod settings (one tab per table).

## Compatibility

- LunaLib is optional. Without it the Lite values apply.
- Safe to add to or remove from a game in progress. Some values (like how
  many derelicts can be recovered) are fixed when the sector is made, so they follow the setting
  the campaign was started with.
- Another mod that changes the same survival settings: the one loaded later wins.
